## 🚧 Not ready yet

This one is still to be written. The mod loads and does nothing; there is no reason to
install it yet.

Trains are the hardest of the three addons, so they are last. A ship is one solid thing
that moves as a unit; a train bends. Each carriage has to be drawn and moved separately,
or a train on a curve looks like a plank.

When it lands you will get what the other two already give you: the carriages themselves,
with their real blocks and textures, running along the track in real time - not a dot
sliding along a line.
